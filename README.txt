KARMA TEKRI KHEL VIKAS SANGATHAN WEBSITE

Pages included:
- index.html (Home)
- about.html (About Us)
- training.html (Training & Activities)
- events.html (Events & News)
- gallery.html (Photo Gallery)
- contact.html (Contact)

HOW TO OPEN
1. Extract this ZIP file.
2. Keep the assets folder beside all HTML files.
3. Open index.html in a web browser.
4. Use the navigation menu to move between all pages.

Each page contains its own CSS in the HTML file. No CSS compilation, framework, or build step is needed. Images are stored locally in assets/. An internet connection is only needed for the optional Google font.

Content and contact details are based on the supplied SOURCES.pdf and the previously prepared landing page. Training schedules and fees were not supplied, so they are not invented.
